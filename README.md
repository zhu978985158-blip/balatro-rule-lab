# Rule Lab / 规则实验室 — Balatro（小丑牌）Mod

Rule Lab 是作用于 **Balatro / 小丑牌** 的 Steamodded 模组。它为原版牌局增加十二个可以独立开关的强化规则，并提供对局内 F8 设置面板。它不新增 Joker、卡牌图像或独立游戏，也不包含 Balatro 本体。

当前源码版本为 **0.2.0**，原开发环境为 **macOS Steam**。如果你希望在游戏中临时调整商店、出牌次数或小丑效果，可以按需打开某一项；所有规则默认关闭。

## 运行前提

- 自行安装并持有 Balatro。
- Lovely **>= 0.9.0**。
- Steamodded **>= 1.0.0~BETA**。
- 一套与这份 Mod 补丁目标相符的游戏/加载器版本。源码按本机 Balatro 1.0.x 结构编写，不代表已经适配任何后续更新。

Lovely 和 Steamodded 都需要自行安装。本仓库不附带它们的二进制，也不会自动修改游戏启动入口。

## 十二个规则

| 分类 | 开关 | 设计作用与次数限制 |
| --- | --- | --- |
| 经济商店 | 首购免费 | 每个商店的第一次购买价格设为0。 |
| 经济商店 | 增强回收 | 出售 Joker 或消耗牌时额外获得2元。 |
| 经济商店 | 商店回声 | 重掷前记住商店第一张 Joker，下一次生成商店卡时复制其类型及版本。 |
| 出牌牌组 | 额外行动 | 每回合额外获得一次出牌和一次弃牌。 |
| 出牌牌组 | 首手回响 | 每个盲注的第一手牌获得1.5倍计分。 |
| 出牌牌组 | 万能改写 | 每个盲注第一次出牌按同花顺（Straight Flush）结算牌型，盲注内只触发一次。 |
| 小丑版本 | Joker超频 | 每个 Joker 每回合首次触发时追加一次触发。 |
| 小丑版本 | 原版升阶 | 原版 Joker 返回的数值效果翻倍；Blueprint 与 Brainstorm 避免重复放大。 |
| 小丑版本 | Edition放大 | 放大 Foil、Holographic、Polychrome 和 Negative 的对应效果。 |
| 盲注连胜 | 失败保底 | 每局第一次失败的盲注自动视为通过，一局仅一次。 |
| 盲注连胜 | Boss重选 | 为 Boss 盲注提供一次额外免费重选。 |
| 盲注连胜 | 无弃牌奖励 | 不使用弃牌击败盲注后，下一回合获得一次出牌和3元。 |

这是源码中的功能设计说明。本次公开整理未重新逐项进行游戏内效果验收；加载器和游戏更新可能影响补丁命中。

## 安装

1. 关闭游戏，先确认 Lovely 与 Steamodded 已正常安装。
2. 下载本仓库，把包含 `main.lua`、`config.lua`、`lovely.toml`、`rule_lab.json` 的文件夹命名为 `RuleLab`。
3. 将 `RuleLab` 放进你的 Balatro Mods 目录。原 macOS Steam 环境使用：

   ```text
   ~/Library/Application Support/Balatro/Mods/RuleLab/
   ```

4. 通过已配置加载器的方式启动 Balatro，在 Mods 列表中确认“规则实验室”已加载。

文件结构应为 `Mods/RuleLab/main.lua`，不要多套一层下载后的仓库文件夹。其他系统请使用自己的加载器所识别的 Mods 目录；本项目未做 Windows 原生实机验证。

## 使用

进入牌局后按 **F8** 打开“规则实验室·当前牌局”，在经济商店、出牌牌组、小丑版本、盲注连胜四个分页中选择开关，按“返回牌局”继续。

主菜单 Mods 配置页设置新局默认开关；F8 面板优先修改当前牌局状态。关闭开关不会撤销已经获得的现金、出牌次数、卡牌变化或已结算分数，也不会刷新已经消耗的一次性机会。测试前请自行备份需要保留的游戏进度。

## 文件与开发

- `main.lua`：规则状态、回合事件、UI和效果逻辑。
- `lovely.toml`：对原版函数的注入位置及补丁文本；游戏更新后首先需要核对这些目标。
- `config.lua`：默认开关，全部为关闭。
- `rule_lab.json`：Steamodded 元数据、依赖与入口。

`lovely.toml` 保留现有 `dump_lua=true` 开发选项，运行时可能生成调试Lua文件。忽略规则已排除日志和调试目录，发布时不要把这些原游戏派生文件提交到仓库。

## 卸载与恢复

关闭 Balatro，移出或删除 `Mods/RuleLab` 文件夹即可停止加载本 Mod。本仓库不会替你卸载 Lovely 或 Steamodded，也不提供原版游戏文件。移除 Mod 不会自动撤销已经写入牌局进度的效果。
